## 📌 About This Project

A comprehensive web application designed to track coding progress, manage contests, and maintain problem-solving leaderboards for programming clubs and communities. Features seamless Google Sheets integration for real-time data management.

## 🚀 Key Features

- 👤 **Profile Section**: Track Codeforces profile data and statistics
- 🏆 **Club Leaderboard**: View rankings of club members
- 🎯 **Contest Management**: Track upcoming and past SPSC contests
- 📊 **Problem Solve Leaderboard**: Google Sheets integration for progress tracking
- 🥇 **Rank Badges**: Gold, Silver, Bronze recognition system
- 🔥 **Streak Recognition**: Consecutive day solving badges
- 📱 **Responsive Design**: Works on all devices

## 🛠️ Technologies Used

- **HTML5** - Structure and semantic markup
- **CSS3** - Styling and responsive design
- **JavaScript (ES6)** - Dynamic functionality and API integration
- **Google Sheets API** - Real-time data synchronization
- **Google Forms** - Data collection interface
- **RESTful APIs** - External data integration

## 🏆 Leaderboard Features

### Rank Badges
- 🥇 **Gold**: Top solver
- 🥈 **Silver**: Second place  
- 🥉 **Bronze**: Third place

### Streak Recognition
- 🔥 **Streak Solver Badge**: 3+ consecutive days of problem solving
- 📈 **Streak Counter**: Display for each participant
- 📊 **Progress Tracking**: Visual representation of consistency

---

## 🔧 Usage

1. **Open Application**: Launch `index.html` in a web browser
2. **Navigate**: Go to **"Problem Board"** section
3. **Submit Progress**: Enter name and problems solved
4. **View Leaderboard**: See rankings with badges and streaks
5. **Real-time Sync**: Data automatically stored in Google Sheets
